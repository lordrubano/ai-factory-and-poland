# AI-фабрика и первое рабочее место в Польше

Веб-комплект: анимация развития AI-фабрики, шесть перелистываемых листов польского этапа, PDF-презентация и профессиональное приложение.

Основа польского этапа — `TZ_POLAND_STAGE_A_v1.1_2026-10-07.docx`. Содержание листов и документов сохранено. Цены являются ориентирами из этой версии ТЗ и требуют согласования перед покупкой.

Откройте `index.html`. Инфографика переключается кнопками, номерами листов и клавишами со стрелками. Доступен полноэкранный режим. Установка программ и авторизация для просмотра сайта не требуются.

GitHub Pages: источник `main`, корневая папка `/`. Для статических файлов используется `.nojekyll`.
